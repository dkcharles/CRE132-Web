# CRE132

The CRE132 course site: learn C# in the browser. Nothing to install — code
compiles and runs in the page via WebAssembly and Roslyn.

Live site: <https://dkcharles.github.io/CRE132-Web/>

- `web/CRE132.Web/` — the Blazor WebAssembly front-end.
- `engine/Tests/` — xUnit tests. Run with `dotnet test engine/Tests`.
- `docs/` — internal notes, specs and plans. Not student-facing.

Design: [docs/specs/2026-08-24-cre132-web-course-site-design.md](docs/specs/2026-08-24-cre132-web-course-site-design.md)
